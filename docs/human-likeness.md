# 更拟人可以加什么（`0.2.0` 已实现）

判断标准：只有同时满足三条，才值得由插件实现。

1. **需要跨轮次、跨天的持久状态**——MaiBot 人格提示词是无状态的。
2. **需要随时间衰减或累计**——例如余怒、能量、关系余温。
3. **需要按用户区分并长期演进**——同一句话对刚认识的人和老朋友分量不同。

MaiBot 原生就能表达的（人格口吻、追问习惯、好消息回应、道别语气、事实回指、打字节奏、偏好设定、主动发消息动作）**不再实现**，只写进人格配置。

## 统一缩放：亲密度

所有拟人效果都乘以 `closeness`（0~1），避免"刚认识就用老友量度"：

```
closeness = 0.6 × 关系阶段进度 + 0.4 × max(0, 三维好感均值)
实际幅度 = 基准值 × (0.1 + 0.9 × closeness)
```

没有好感记录或好感为 0 时按 0 计，只有正向好感才抬高性能；完全陌生时最多保留约 10% 的幅度。实现见 `engine_humanlike.closeness` / `scale_by_closeness`。

回复侧每次最多注入 **2 条**即时提示（优先级：修复 > 缺席/重逢 > 边界 > 跟进 > 余怒 > 能量 > 峰值 > 风格），避免多条指令互相打架、把回复变成清单。提示只写**事实与状态**（"对方最近 25 条消息平均 1 字"），不写"回复要短"这类指令，表达交给模型。

## 两个反拟人的陷阱

**1. 把"话少"当成"冷淡"**

消息短可能是这个人的常态，也可能是关系降温。两者的区别不在绝对长度，而在**相对自己的基线**：

- 样本达到 20 条时冻结一条基线（此后不再更新）；
- 只有最近均值相对基线变化 ≥ 50% 才注入"最近平均 3 字，此前平均 12 字"这样的事实；
- 天生话少、始终稳定的用户不会触发，也不会被要求模仿。

模型看到的是"变化"，不是"对方话少"这个标签，因此不会给安静的人贴上冷淡的结论。

**2. 状态压过人格（OOC）**

状态只回答"此刻发生了什么"，不回答"该怎么表现"：

- 注入的一律是事实（"关系温度仍未恢复 0.12"），不是行为指令（"语气收敛一点"）；
- 每次注入末尾都声明：呈现方式由人格决定，不得为表现状态而改变性格、价值观或口吻；
- 记忆回指要求当前话题与旧事有词面交集，避免突然提起无关往事；
- 状态幅度按亲密度缩放，并有每日/单次上限。

## 度量、失效与边界

**提示采纳率**：每次注入的提示都会写一条 `hint_stats(kind, date, injected, used)`；回复返回后，用词面交集判断这条提示是否真的被用上（例如回复里出现"面试"即认为跟进被提及）。WebUI 显示当日 `kind used/injected`。坚持为 0 的类型可以视为"模型不需要"，考虑关闭。

**失效清理**：

- 跟进事项超过 `followup_ttl_hours` 自动过期；
- 修复提示超过 `repair_ttl_hours` 自动过期；
- 边界话题超过 `boundary_ttl_days` 自动失效；
- Planner 超过 `work_ttl_hours` 没处理的维护任务直接丢弃，避免队列无限堆积。

**不归插件管的能力**：发送节奏（延迟、分段、正在输入）属于宿主或其他插件；本插件只决定"何时、找谁、为什么"，不拦截消息发送。强依赖 Planner 的抽取类功能在 Planner 不调用工具时会停摆，这是宿主流程限制，只能通过兜底（时间词缺席识别）和过期清理降低影响。

## 评审修复（0.3.1）

| 问题 | 修法 |
| --- | --- |
| “不开心”被识别为开心 | 否定词前缀优先判定，正向词匹配跳过被否定的出现 |
| 修复/跟进串到别的用户 | `pending_relationship_events` 增加 `user_id` 过滤，全部调用点传入当前用户 |
| 情绪残留是全局的 | `carry_over_until:{user_id}` 按用户存储，只影响该用户的跟进提示 |
| 披露深度开关无效 | 阶段事实直接由 `disclosure_hint` 生成并注入 |
| 群聊耗光表达能量 | 只有私聊消息消耗能量，群聊不消耗 |
| 群聊暴露私人提示 | 群聊只保留修复类提示 |
| 自我披露计数≈消息数 | 去掉裸“我”，只认明确的自我披露句式 |
| 关键词子串误报 | “麻烦/累计”不再算倾诉；条件句不算峰值 |
| PAD 数值进提示词 | 回复侧只保留标签与表达状态 |
| 采纳统计把复述算采用 | 回复包含提示语原句时不计入采纳 |
| 跟进不相关也提 | 跟进需与当前话题相关或当前消息很短 |
| 长期不来往不冷却 | 超过 14 天无互动且非已知缺席时，好感每天向 0 轻微回落 |

## 评审修复（0.3.2）

| 问题 | 修法 |
| --- | --- |
| 情绪残留说明与实际不符 | 配置改为“负面情绪后暂停跟进”，删除死代码 `carry_over_scale` |

## 边界与伦理

- 不模拟嫉妒、冷暴力、情绪勒索或"你不理我"式施压。
- 不编造紧急事件或虚假记忆来制造话题。
- 缺席与重逢只表达角色自己的状态，不评价用户。
- 所有幅度有上限，并提供关闭开关；生人几乎不触发。
